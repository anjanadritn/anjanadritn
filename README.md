- API endpoints for doctors, queues, and health checks.

**Technology stack:** Python · Flask · React · MongoDB · Machine Learning · Git · GitHub · Deployment

**DevOps learning opportunities**

- Add monitoring, logging, and health checks.
- Explore automated testing and deployment.
